# Repository working rules

- Use Node.js 22, TypeScript, Express, portable PostgreSQL/Redis adapters, structured logs, OpenTelemetry, and AlgaGuard contracts.
- Never commit secrets, production credentials, signing keys, or provider-specific domain types.
- Keep health/readiness, graceful shutdown, environment validation, problem details, tests, and container validation passing.
- Do not introduce NestJS, Java/Spring, Python services, Firebase, Kafka, or Kubernetes in this phase.
- Do not claim deployment or production readiness without evidence.
